DAY 01

神经网络基础

从张量、层与损失函数建立直觉

张量 带形状与数据类型的多维数值块，是模型输入、权重和中间结果的统一表示。 Shape 描述各维长度及其语义，例如 NCHW 的 batch、通道、高和宽。 激活函数 在线性变换后加入非线性，使多层网络能表达复杂边界。 MAC 一次乘加运算；常用于粗略估算计算量。 理解神经网络如何把输入张量变成可优化的预测，并能读懂一次前向与反向传播。 18 分钟 · 历史 + 图解 + 动画 DAY 02

训练与推理

理解离线训练与设备端执行的边界

Epoch 训练集完整遍历一次。 Batch 一次用于计算梯度的一小批样本。 eval 模式 让 Dropout、BatchNorm 使用推理语义的模式。 优化器 依据梯度更新参数的算法及其状态。 区分训练图、推理图和部署图，知道哪些状态必须保留、哪些可以折叠。 17 分钟 · 历史 + 图解 + 动画 DAY 03

模型格式

让模型成为可移植的中间表示

计算图 以节点和边描述张量如何经过算子得到输出。 ONNX opset 模型声明的算子语义版本。 Metadata 随模型保存的名称、词表、量化或配置说明。 Runtime 加载模型并调度算子执行的程序。 能从计算图、权重张量、元数据三个角度阅读 ONNX、TFLite、GGUF 等格式。 18 分钟 · 历史 + 图解 + 动画 DAY 04

量化

用更少的 bit 换取更低的存储与带宽

Scale 整数码与真实数值之间的比例系数。 Zero-point 映射中代表真实零值的整数偏移。 校准集 用于估计激活范围的代表性输入样本。 Per-channel 为不同权重通道分别使用量化参数。 掌握对称/非对称量化、scale/zero-point，并能判断误差来源。 19 分钟 · 历史 + 图解 + 动画 DAY 05

算子

从数学定义走到可执行 kernel

Kernel 针对具体硬件实现一个算子的低层计算代码。 Layout 张量维度在内存中的排列方式，如 NCHW 或 NHWC。 Fusion 将多个连续算子合并为一次执行。 Tiling 把大计算分块以适配寄存器或 cache。 理解算子语义、内存布局、kernel 选择和算子融合之间的关系。 18 分钟 · 历史 + 图解 + 动画 DAY 06

非 LLM 端侧模型训练与部署

把视觉/音频/传感器模型真正烧进设备

代表性数据 覆盖真实设备工况的数据集合。 Tensor arena 为 MCU 推理预分配输入、输出和中间张量的内存区。 前处理 将原始传感器数据变成模型输入的步骤。 混淆矩阵 按真实类别与预测类别统计的表。 完成数据、训练、导出、量化、部署、验证的闭环，重点覆盖 MCU 常见小模型。 19 分钟 · 历史 + 图解 + 动画 DAY 07

内存、带宽、MCU/NPU

从“能跑”进化到“跑得稳”

峰值活跃内存 某一时刻同时需要保留的所有 buffer 总量。 带宽 单位时间可搬运的数据量。 PSRAM 通过外部接口连接的大容量 RAM。 Delegate 将支持子图交给专用加速器的后端机制。 用峰值 RAM、持续带宽和算力预算解释端侧性能，而不是只看参数量。 18 分钟 · 历史 + 图解 + 动画 DAY 08

端侧视觉模型

从摄像头帧到可用事件

Stride 同一行相邻像素数据在内存中的跨度。 Letterbox 保持比例缩放并填充边缘的 resize 方法。 NMS 去除高度重叠候选框的后处理。 Buffer ownership 规定谁可读写、何时归还 buffer 的规则。 掌握检测/分类/分割的选择，以及摄像头、颜色格式、缩放和后处理的流水线。 20 分钟 · 历史 + 图解 + 动画 DAY 09

Tokenizer

理解文本如何变成模型可消费的整数流

Vocabulary token 到整数 id 的映射表。 BPE 通过合并常见子串构建 token 的算法。 Special token 表示开始、结束、角色等控制含义的 token。 Chat template 将消息列表格式化为模型训练期预期字符串的模板。 能解释 vocabulary、merges、special tokens、padding 与 token budget，并定位端侧分词开销。 17 分钟 · 历史 + 图解 + 动画 DAY 10

KV Cache

用内存换取 Decode 阶段的重复计算

Prefill 一次处理已有 prompt 并建立 KV cache 的阶段。 Decode 逐 token 生成并追加状态的阶段。 KV cache 保存历史 token 的 key/value 张量。 GQA 多个 query head 共享较少 K/V head 的注意力设计。 理解 Prefill/Decode、K/V 张量布局、cache 量级与长上下文代价。 19 分钟 · 历史 + 图解 + 动画 DAY 11

LLM Runtime

把模型、缓存和生成循环组织起来

Context 一次推理会话持有的 token 和 KV 状态。 Sampling 从 logits 选择下一个 token 的策略。 Streaming 边生成边发送输出而非等待完整回复。 Cancellation 中止已失效请求并释放资源的机制。 理解 runtime 的生命周期、计算图、采样器和内存管理，并能划分 ESP32 与 Linux 主机职责。 18 分钟 · 历史 + 图解 + 动画 DAY 12

LLM 量化与 GGUF

把权重压到可部署的模型文件

GGUF GGML 系执行器使用的模型容器格式。 Block quantization 按块共享 scale 等参数的低比特编码。 Weight-only 只量化权重、激活保持较高精度的策略。 mmap 将文件映射到虚拟内存按需访问。 理解 block quantization、混合精度、权重元数据及 GGUF 容器的关系。 18 分钟 · 历史 + 图解 + 动画 DAY 13

端侧 LLM 推理框架

比较 Runtime、Backend 与编译型框架

Backend 把 runtime 请求映射到特定硬件的实现层。 Offload 把部分层或子图交给加速器执行。 Partition 按支持能力切分图的过程。 Fallback 加速器不支持时转由默认实现执行。 建立 GGUF/计算图/runtime/backend/kernel 的分层模型，知道如何选择 llama.cpp、MLC、ONNX Runtime GenAI 或 ExecuTorch。 19 分钟 · 历史 + 图解 + 动画 DAY 14

性能分析

把“感觉慢”变成可定位的预算

TTFT 从请求发出到首个 token 返回的时间。 p95 95% 请求不超过的尾延迟分位数。 Warm-up 正式测量前预热 runtime、cache 和频率。 Joules/token 每生成一个 token 的能耗。 用端到端指标、分阶段计时、硬件计数器和功耗测量定位瓶颈。 17 分钟 · 历史 + 图解 + 动画 DAY 15

整合：端侧 AI 工程链路

把 14 天知识收束成可交付项目

安全边界 必须由确定性组件强制执行的权限和范围限制。 降级 依赖不可用时切换到安全且有限的功能。 OTA 远程更新固件或模型的交付机制。 验收报告 记录功能、性能、能耗和故障测试条件的证据。 完成从数据与模型到设备、主机、性能和产品约束的系统设计。 20 分钟 · 历史 + 图解 + 动画 DAY 16

大规模 LLM Infra：从芯片到集群

把一次训练迭代与一次在线请求放回真实的数据移动、并行拓扑和服务 SLO 中

Goodput 在给定正确性与 SLO 约束内完成的有效工作量，而非原始峰值吞吐。 Collective 一组 rank 共同参与的数据交换与规约操作，如 all-reduce、all-gather。 KV Cache 保存历史 token 的 attention Key/Value，避免 Decode 重算旧上下文。 PD 解耦 把 Prefill 与 Decode 放到可独立调度和扩缩容的 worker 池。 建立跨越寄存器、HBM、互连、网络、存储与调度器的统一成本模型；能解释 DP、TP、PP、CP、EP、FSDP/ZeRO 分别切什么、搬什么；能用 TTFT、ITL、goodput 与尾延迟判断训练或服务方案，而不是用峰值 FLOPS 或项目名称代替系统分析。文中易变项目状态截至 2026-08-11 核验。 28 分钟 · 历史 + 图解 + 动画 DAY 17

端侧 LLM Infra：从云端经验到设备约束

把 I/O-aware、分页状态与可运营性迁移到手机、PC、SBC 和 MCU 协同系统

Delegate 接收已分区子图并在 CPU/GPU/NPU 等特定后端编译执行的接口。 Peak RSS 进程在测量期间达到的最大常驻物理内存，用于发现加载或 Prefill 峰值。 能耗/token 每生成或处理一个 token 消耗的能量，比瞬时功率更能联系有效工作。 显式回退 在权限、隐私、时限与失败行为已定义的条件下转到另一 backend 或云端。 能先划清 ESP32/MCU、Linux Edge Host 与云端的能力边界，再为同一 checkpoint 选择量化、打包、编译/委派、runtime 与回退路径；能同时测量质量、TTFT、ITL、峰值 RSS、能耗/token、温度和热降频，并解释为什么权重能装入 RAM 或 NPU TOPS 很高仍不保证端到端可用。易变项目状态截至 2026-08-11 核验。 28 分钟 · 历史 + 图解 + 动画
