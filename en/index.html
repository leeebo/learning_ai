DAY 01

Neural Network Fundamentals

Build intuition from tensors, layers, and loss functions

Tensor A multidimensional numeric block with a shape and data type—the common representation for model inputs, weights, and intermediate results. Shape The length and meaning of each dimension, such as batch, channel, height, and width in NCHW. Activation function A nonlinearity applied after a linear transform that lets multilayer networks express complex boundaries. MAC One multiply–accumulate operation, commonly used for a rough estimate of compute. Understand how a neural network turns input tensors into optimizable predictions, and learn to follow one forward and backward pass. 18 min · history + visual analogy + animation DAY 02

Training and Inference

Understand the boundary between offline training and on-device execution

Epoch One complete traversal of the training set. Batch A small group of samples used to calculate one gradient update. eval mode A mode that makes Dropout and BatchNorm use inference semantics. Optimizer An algorithm—and its state—that updates parameters from gradients. Distinguish training, inference, and deployment graphs, and know which state must be retained and which can be folded away. 17 min · history + visual analogy + animation DAY 03

Model Formats

Turn a model into a portable intermediate representation

Computation graph A set of nodes and edges describing how tensors pass through operators to produce outputs. ONNX opset The version of operator semantics declared by a model. Metadata Names, vocabularies, quantization details, or configuration saved with a model. Runtime Software that loads a model and schedules its operators for execution. Learn to read formats such as ONNX, TFLite, and GGUF from three perspectives: computation graph, weight tensors, and metadata. 18 min · history + visual analogy + animation DAY 04

Quantization

Trade fewer bits for lower storage and bandwidth

Scale The proportional factor between an integer code and its real value. Zero-point The integer offset that represents real zero in the mapping. Calibration set Representative input samples used to estimate activation ranges. Per-channel Using separate quantization parameters for different weight channels. Master symmetric and asymmetric quantization, scale and zero-point, and learn to identify sources of error. 19 min · history + visual analogy + animation DAY 05

Operators

Move from mathematical definitions to executable kernels

Kernel Low-level code that implements an operator for specific hardware. Layout The arrangement of tensor dimensions in memory, such as NCHW or NHWC. Fusion Combining several consecutive operators into one execution. Tiling Partitioning a large computation to fit registers or cache. Understand the relationship among operator semantics, memory layouts, kernel selection, and operator fusion. 18 min · history + visual analogy + animation DAY 06

Training and Deploying Non-LLM Edge Models

Put vision, audio, and sensor models onto a real device

Representative data A dataset covering real device operating conditions. Tensor arena A memory region preallocated for MCU inference inputs, outputs, and intermediate tensors. Preprocessing The steps that transform raw sensor data into model input. Confusion matrix A table counting predicted classes against true classes. Complete the loop from data, training, export, and quantization to deployment and validation, with an emphasis on small models commonly used on MCUs. 19 min · history + visual analogy + animation DAY 07

Memory, Bandwidth, MCU, and NPU

Progress from “it runs” to “it runs reliably”

Peak live memory The total size of all buffers that must be retained at the same instant. Bandwidth The amount of data that can be moved per unit time. PSRAM High-capacity RAM connected through an external interface. Delegate A backend mechanism that assigns supported subgraphs to a specialized accelerator. Explain edge performance using peak RAM, sustained bandwidth, and compute budgets instead of parameter count alone. 18 min · history + visual analogy + animation DAY 08

On-Device Vision Models

From camera frames to actionable events

Stride The memory distance between adjacent pixel data on the same row. Letterbox A resize method that preserves aspect ratio and pads the borders. NMS Post-processing that removes highly overlapping candidate boxes. Buffer ownership Rules defining who may read or write a buffer and when it must be returned. Learn how to choose among detection, classification, and segmentation, and understand the complete camera, color-format, resizing, and post-processing pipeline. 20 min · history + visual analogy + animation DAY 09

Tokenizer

Understand how text becomes an integer stream a model can consume

Vocabulary A mapping from tokens to integer IDs. BPE An algorithm that constructs tokens by merging frequent substrings. Special token A token carrying control meaning such as beginning, end, or role. Chat template A template that formats a message list into the string expected during model training. Explain vocabularies, merges, special tokens, padding, and token budgets, and locate the cost of tokenization on edge systems. 17 min · history + visual analogy + animation DAY 10

KV Cache

Trade memory for less repeated work during decoding

Prefill The phase that processes the existing prompt at once and builds the KV cache. Decode The phase that generates one token at a time and appends state. KV cache Key/value tensors retained for historical tokens. GQA An attention design in which multiple query heads share fewer K/V heads. Understand prefill and decode, K/V tensor layouts, cache sizing, and the cost of long contexts. 19 min · history + visual analogy + animation DAY 11

LLM Runtime

Orchestrate the model, cache, and generation loop

Context The tokens and KV state held by one inference session. Sampling The policy used to choose the next token from logits. Streaming Sending output while it is generated instead of waiting for a complete response. Cancellation A mechanism that aborts an obsolete request and releases its resources. Understand the runtime lifecycle, computation graph, sampler, and memory management, and divide responsibilities between an ESP32 and a Linux host. 18 min · history + visual analogy + animation DAY 12

LLM Quantization and GGUF

Compress weights into a deployable model file

GGUF A model-container format used by GGML-family executors. Block quantization Low-bit encoding in which values in a block share parameters such as a scale. Weight-only A strategy that quantizes weights while keeping activations at higher precision. mmap Mapping a file into virtual memory for on-demand access. Understand block quantization, mixed precision, weight metadata, and their relationship to the GGUF container. 18 min · history + visual analogy + animation DAY 13

On-Device LLM Inference Frameworks

Compare runtimes, backends, and compiler-based frameworks

Backend The implementation layer that maps runtime requests onto specific hardware. Offload Assigning some layers or subgraphs to an accelerator. Partition The process of dividing a graph according to backend capabilities. Fallback Using the default implementation when an accelerator lacks support. Build a layered model of GGUF/computation graph/runtime/backend/kernel and learn when to choose llama.cpp, MLC, ONNX Runtime GenAI, or ExecuTorch. 19 min · history + visual analogy + animation DAY 14

Performance Analysis

Turn “it feels slow” into a budget you can localize

TTFT The time from request submission to the first returned token. p95 The tail-latency percentile that 95% of requests do not exceed. Warm-up Priming the runtime, caches, and clock frequency before formal measurement. Joules/token The energy consumed to generate one token. Locate bottlenecks with end-to-end metrics, stage-level timing, hardware counters, and power measurements. 17 min · history + visual analogy + animation DAY 15

Integration: The Edge-AI Engineering Pipeline

Turn 14 days of knowledge into a deliverable project

Safety boundary Permission and range constraints that a deterministic component must enforce. Graceful degradation Switching to safe, limited functionality when a dependency is unavailable. OTA A delivery mechanism for remotely updating firmware or models. Acceptance report Evidence recording the conditions of functional, performance, energy, and fault tests. Design a complete system spanning data and models, device and host, performance, and product constraints. 20 min · history + visual analogy + animation DAY 16

Large-Scale LLM Infrastructure: From Chips to Clusters

Place one training iteration and one online request back inside real data movement, parallel topology, and serving SLOs

Goodput Useful work completed within correctness and SLO constraints, rather than raw peak throughput. Collective A coordinated data exchange or reduction across ranks, such as all-reduce or all-gather. KV cache Stored attention keys and values for prior tokens, allowing decode to avoid recomputing old context. PD disaggregation Placing prefill and decode in worker pools that can be scheduled and scaled independently. Build one cost model spanning registers, HBM, scale-up links, networks, storage, and schedulers. Explain what DP, TP, PP, CP, EP, and FSDP/ZeRO partition, what each moves, and where it belongs. Judge training and serving designs with TTFT, ITL, goodput, and tail latency rather than substituting peak FLOPS or project names for system analysis. On-Device LLM Infrastructure: Adapting Cloud Lessons to Device Constraints

Adapt I/O awareness, paged state, and operability to phones, PCs, SBCs, and MCU-coordinated systems

Delegate An interface that compiles and runs a partitioned subgraph on a CPU, GPU, NPU, or other backend. Peak RSS The maximum resident physical memory reached by a process during measurement, exposing load or prefill peaks. Energy per token Energy spent per processed or generated token, linking power consumption to useful work. Explicit fallback Moving to another backend or the cloud only under defined permission, privacy, deadline, and failure policy. Draw the boundary among ESP32-class MCUs, Linux edge hosts, and the cloud before selecting quantization, packaging, compilation or delegation, runtimes, and fallback for one checkpoint. Measure quality, TTFT, ITL, peak RSS, energy per token, temperature, and thermal throttling together, and explain why fitting weights in RAM or advertising high NPU TOPS does not guarantee an acceptable product.
